How to wire a bot to this

The lab does not run a bot. It keeps the record a bot produces, and it decides what that record has earned. A bot connects by posting each completed paper trade:

POST /api/lab/fills
Content-Type: application/json
Cookie: <the session from /api/access/login>

{ "strategy": "farm", "pnl_usd": -12.40, "note": "optional" }

Rules the lab enforces, so a misconfigured bot cannot quietly do the wrong thing:

  • strategy must be one the lab knows. An unknown name is rejected rather than silently created.
  • Every fill is recorded as paper. There is no field that marks one as real, because there is no real mode.
  • Losses count. A bot that only reports its winners produces a record that will unlock something it should not — post every closed trade, including the bad ones.
  • Nothing you post can move money, place an order, or reach an exchange. There is no code here that does any of that.

What this is not

This is a test of software, run on simulated trades. It is not investment advice, not a managed account, not a service, and not an offer of anything. No money changes hands in either direction, and no result here is a prediction of any other result.

Automated trading loses money as well as making it. Nothing on this page should be read as a suggestion that it will not.

Whether this software may one day place orders in an account belonging to someone other than its owner is a question with a lawyer, and it has not been answered. Until it is, the lab has no live mode — not a disabled one, none.
